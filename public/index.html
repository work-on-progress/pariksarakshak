Enforcement

Three layers, and each one holds on its own.

A rule enforced only in JavaScript is a suggestion. Every restriction below lives at the lowest layer that can actually enforce it.

On the machine

Safe Exam Browser

The operating system refuses the shortcut, so there is nothing for a script to intercept.

  • Screenshots and screen recorders capture black
  • Alt+Tab, Win+Tab and virtual desktops disabled
  • Second monitors blanked, virtual machines refused
  • Quitting needs the invigilator's password
In the database

Row-level security

Students hold a public key by design. Postgres decides what that key may see.

  • Answer keys are in no row a student can read
  • Hidden test cases never leave the server
  • Marks are written by the server, never posted by the page
  • Answers lock the moment a paper is submitted
In the room

Local face check

The camera stream stays in the browser. Only the event travels, so there is no video to store or leak.

  • No face, or more than one face, for four seconds
  • Window blur, tab hidden, full screen exited
  • Alerts reach your console in about a second
  • Nothing is recorded or uploaded
One exam, start to finish

Four moves.

01

Write the paper

Type a topic or paste your lecture notes and choose the mix — multiple choice, fill in the blanks, long answers, coding problems. Questions come back structured, with starter code and test cases already split into visible and hidden. Edit anything, or write your own by hand.

02

Seal the lab

Students sign in on an ordinary browser, pick their paper and press start. The browser offers to open Safe Exam Browser, the machine locks, and they are signed in automatically with no password to retype. One configuration file, made once, serves every exam you will ever run.

03

Watch the room

Answers save as they are typed, so a power cut costs nothing. Code runs against the visible tests as often as a student likes; submitting runs the hidden ones too, on the server. The roster shows who is sitting, who has finished and who has raised flags.

04

Return the marks

Objective questions and coding problems are graded the instant the paper is submitted. Long answers wait for you, and marking one recomputes the total. Export the sheet as CSV when you are done.
